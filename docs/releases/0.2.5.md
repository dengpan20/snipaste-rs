# 映贴 0.2.5

## 本版更新

- 截图和桌面贴图的全局热键均可自定义：从托盘或菜单栏打开“热键设置…”，点击按键框录入组合后保存。
- 保存后立即生效，重启后保留；支持恢复默认、取消修改和 Esc 取消按键录入。
- 检查重复热键和其他应用占用。自定义热键冲突时保留原设置，并提示选择其他组合。
- 默认热键继续使用候选键策略；菜单、截图提示和操作说明显示实际生效的按键。
- 设置窗口关闭后恢复全局热键，并按现有空闲策略释放图形资源。

## 使用方法

Windows：右键点击托盘图标 → **热键设置…**。Mac：点击菜单栏图标 → **热键设置…**。

普通按键需要搭配 Ctrl、Alt / Option 或 Win / ⌘；功能键可以单独使用。设置窗口打开期间暂停截图和贴图热键，保存或关闭后恢复。

## 下载与校验

- `yingtie-0.2.5-win64.zip`：Windows x64 便携包，解压运行 `snipaste-rs.exe`。
- `yingtie-0.2.5.exe`：Windows x64 独立程序。
- `yingtie-0.2.5-macos-arm64.zip`：macOS 14+ Apple Silicon 应用包，将“映贴.app”移入“应用程序”。
- `SHA256SUMS.txt`：以上文件的 SHA-256 校验值。

更新前请先退出旧版。设置保存在当前用户目录中，替换程序不会清除已保存的热键。

## 验证与范围

- Windows：155 项单元测试、格式与零告警代码检查通过；截图、标注、导出、剪贴板、二维码及资源生命周期原生验收通过。热键录入、重复键与占用提示、保存、重启加载、取消和恢复默认已进行桌面交互验收。
- Mac 应用由 Apple Silicon CI 进行格式检查、原生桥编译、代码检查、单元测试、release 构建和签名校验；本版新增热键设置尚未进行 Mac 真机交互验收。
- Windows 程序未进行代码签名；Mac 应用使用 ad-hoc 临时签名，未进行 Developer ID 签名和 Apple 公证。
