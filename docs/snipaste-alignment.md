# 当前版本重新规划：以 Snipaste 的截图流程为基准

版本：0.2.3 · 2026-10-12 · 当前验收平台：Windows x64

## 1. 操作流程

```text
托盘待命
  → F1 / 单击托盘：捕获并冻结桌面
  → 移动鼠标：预选指针下的窗口
  → 单击：确定窗口；拖动：自由框选
  → 选区旁显示工具条：调整范围、标注、撤销
  → 勾号 / Enter / Ctrl+C / 双击：合成选区，写入图片剪贴板，关闭遮罩
  → 在支持图片的应用中 Ctrl+V 粘贴
```

截图、复制、保存、二维码识别、贴图均使用本次截图的冻结像素。工具条、尺寸标签、选区边框与输入框不进入导出图片。

## 2. 界面规则

- 桌面作为底图，选区外压暗，选区内保持原色。
- 蓝色选区边框、八个缩放手柄、物理像素尺寸标签。
- 预选时显示光标附近的放大镜、坐标、像素颜色；选定后显示浅色图标工具条。
- 工具条默认靠选区右下方，靠近底边时移动到上方，并限制在屏幕内。
- 矩形、椭圆、箭头、画笔、记号笔、马赛克、文字、橡皮擦；再次点击当前绘图工具回到选择工具。
- 几何/文字工具显示颜色和相应属性；马赛克/橡皮擦显示框选、涂抹、笔刷大小及打码强度；选择模式收起属性行。
- 末端红色叉号取消，绿色勾号确认。按钮悬停显示操作及快捷键。
- 用户界面只显示操作提示与错误，不显示字体名称、历史栈数量等开发信息。

## 2.1 截图与标注修复（0.2.1）

- 截图遮罩使用不透明冻结底图；隐藏期间先呈现首帧并等待 GPU 完成，再显示窗口。禁用 Windows 窗口过渡动画，收起后等待桌面合成再释放底图。
- 首帧按当前鼠标位置预选窗口，避免显示后再跳一次选区。
- 马赛克修正了矩形草稿没有随拖动更新的问题；支持正向/反向框选、连续涂抹、强度和大小调节。实际采样冻结底图像素，使用缓存纹理，预览与导出共用处理和遮罩。
- 橡皮擦按笔刷轨迹或矩形范围恢复原图，保留区域外标注，支持单击、快速划过、大小调节；一笔对应一次撤销/重做。取消未完成笔刷则丢弃草稿。
- 修正了大于 2048 像素桌面在 debug 首次加载纹理时触发尺寸断言的问题。

框选/自由涂抹的操作参考 [Snipaste 官方高级技巧](https://github.com/Snipaste/feedback/wiki/Advanced-Tips)。

## 2.2 颜色取值（0.2.2）

- 放大镜提供 HEX 和 RGB 两种颜色格式，默认 HEX；按一下 Shift 切换，松开后保留，新截图继续使用当前格式。
- 示例：HEX 显示 `HEX: #123456`，复制 `#123456`；RGB 显示 `RGB: (18, 52, 86)`，复制 `18, 52, 86`。
- 放大镜显示时按 C 复制当前像素颜色，并保留截图界面。Ctrl+C 继续确认并复制截图。
- 已框选后按住 Alt 临时显示放大镜，松开隐藏；文字输入和二维码结果窗口不触发取色快捷键。
- 坐标、颜色显示和复制都读取冻结截图的同一个物理像素；17×17 像素放大镜中央方框对准像素中心。

快捷键参考 [Snipaste 官方说明](https://github.com/Snipaste/feedback/wiki/Key-Bindings)。

## 2.3 内存优化（0.2.3）

- 启动只建立托盘和热键，截图/贴图时按需加载图形设备、字体和窗口。
- 完成或取消截图立即释放底图、马赛克纹理、字体图集、编辑历史与交换链；无贴图时空闲 3 秒后释放图形设备。
- 多个界面共享中文字体文件；最后一个界面关闭后，字体弱缓存允许文件内存释放。
- 像素马赛克每块仅保留一个平均像素，以最近邻采样放大；非整块边缘和负屏幕原点保持原有网格。
- 带标注导出复用预览已上传的底图，不先复制整张裁剪图。二维码识别、PNG 保存和贴图复制取消不必要的 RGBA 拷贝。
- 保留显示前准备首帧的顺序，贴图存在时保留共享图形设备；冷启动与释放后的截图、剪贴板贴图均有原生验收。

测量方法、结果和启动延迟见 [内存优化记录](memory.md)。

## 3. 二维码是选区动作

点击二维码图标或按 Q 后，立即裁剪当前选区的原始底图，在工作线程识别，并弹出结果窗口。

- 不切换绘图工具，不要求再次框选。
- 支持多个二维码、文字和链接内容、反色二维码。
- 识别成功显示内容，点击“复制识别结果”写入文本剪贴板。
- 未识别到时显示提示，可关闭结果、调整选区再重试。
- 不访问识别出的链接。
- 取消截图、关闭结果或开始新截图后，旧任务的结果不会重新打开窗口。

## 4. 已接通的操作

| 操作 | 行为 |
|---|---|
| F1 | 呼出 / 收起截图遮罩；占用时尝试 Ctrl+Shift+F1 等候选键 |
| 单击预选窗口 | 锁定选区 |
| 在预选窗口中拖动 | 从按下位置自由框选 |
| 拖选区边框手柄 | 调整大小 |
| 在选区中拖动 | 移动选区；命中已有标注时移动标注 |
| 方向键 | 1 像素移动选区 |
| Ctrl+方向键 | 10 像素移动选区 |
| Shift+方向键 | 调整选区右边 / 下边 |
| Shift+拖动 | 正方形 / 正圆；箭头以 45° 为单位约束方向 |
| Shift（放大镜显示时） | 在 HEX / RGB 之间切换颜色格式 |
| C（放大镜显示时） | 复制当前像素的颜色值 |
| 按住 Alt | 框选后临时显示放大镜取色 |
| 单击文字工具后点击选区 | 内嵌文字输入，支持中文；Enter 提交，Shift+Enter 换行 |
| Delete / Backspace | 删除选中的标注，可撤销 |
| Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z | 撤销 / 重做标注 |
| Q | 识别当前选区二维码 |
| 勾号 / Enter / Ctrl+C / 选择模式双击 | 确认并复制截图，成功后关闭遮罩 |
| Ctrl+S / 保存图标 | 原生保存对话框，支持 PNG / JPEG；取消后回到截图 |
| 右键 | 文字编辑时提交文字；已选区时重新选择；预选时取消 |
| Esc | 先关闭二维码 / 放弃输入 / 放弃当前拖动；其余状态取消截图 |
| F3 / 贴图图标 | 截图中贴出当前选区；托盘待命时贴出剪贴板图片 |
| 贴图拖动 / 滚轮 | 移动 / 缩放 |
| 贴图 Shift+滚轮 | 调整透明度 |
| 贴图 Ctrl+C / 右键菜单 | 复制原始图片 / 保存、恢复原始大小、关闭 |
| 贴图双击 / Esc | 关闭当前贴图，继续托盘待命 |

每次截图开始清空上次标注及历史，保留用户当前颜色、笔宽、笔刷大小和框选/涂抹偏好。复制失败时保留截图，允许重试。二维码文本复制与图片确认复制分别执行。

## 5. 实现边界

本次完成 Windows 截图主流程及桌面贴图。屏幕捕获使用 GDI；独占全屏游戏、受保护视频内容需要后续 DXGI / WGC 后端。虚拟桌面覆盖按显示器并集计算，裁剪始终使用物理像素；混合 DPI 多屏仍需更多真机验收。

托盘提供 Windows 当前用户的开机启动开关和可见的操作说明窗口。开机启动只在用户点击选项时写入注册表。

当前尚不包含贴图分组与历史库、滚动截图、高级设置和 Linux 捕获后端。0.2.4 已接入 macOS 14+ Apple Silicon 的 ScreenCaptureKit、权限、菜单栏、保存与自启；Mac 真机验收仍需执行，见 [Mac 指南](macos.md)。原架构文档中的性能与内存数字是设计目标，不代表已测量达到。

## 6. 验收方式

普通测试覆盖编辑器、框选时序、按钮点击不穿透、二维码选区边界、反色码及失败提示。Windows 原生验收执行屏幕捕获、带标注导出、图片剪贴板逐像素读回、二维码文本复制、关闭遮罩及贴图 GPU 呈现，并生成界面 PNG。包含高频图像打码、精确笔刷遮罩、局部擦除、单击/快速擦除、撤销重做像素一致性、负屏幕原点和连续三次首个可见帧检查；原图恢复允许 GPU 插值产生的 1 级通道量化误差。0.2.2 增加 HEX/RGB 界面、Shift 切换及按键重复、C 系统剪贴板读回、Alt 取色、文字输入保护和放大镜中心像素检查。

```powershell
. ./scripts/env.ps1
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace

$env:SNIPASTE_QR_FIXTURE_PATH = Join-Path (Get-Location) 'target/acceptance-qr.png'
cargo test -p snipaste-app write_acceptance_fixture -- --ignored
cargo build -p snipaste-app
$env:SNIPASTE_VERIFY_DIR = Join-Path (Get-Location) 'target/acceptance'
./target/x86_64-pc-windows-gnu/debug/snipaste-rs.exe
Remove-Item Env:SNIPASTE_VERIFY_DIR
Remove-Item Env:SNIPASTE_QR_FIXTURE_PATH
```

原生验收只在 debug 构建和显式环境变量下执行，完成后恢复先前的剪贴板图片或文本，报告保存在 target/acceptance/result.txt。
