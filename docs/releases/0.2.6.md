# 映贴 0.2.6

## 本版更新

- 新增完整设置面板：从 Windows 托盘或 Mac 菜单栏打开“设置…”，配置截图 / 贴图快捷键、默认保存文件夹、PNG / JPEG、开机自启、窗口预选及标注偏好。
- 新增序号标注：框选后按 N，点击依次添加圆形数字；按 V 拖动，Delete 删除，支持撤销、重做、复制、保存和桌面贴图。每次新截图从 1 开始。
- 保留 0.2.5 的物理按键录入、冲突检查与默认候选热键策略；打开设置时暂停全局热键，保存或关闭后恢复。兼容读取旧版 hotkeys.json。
- 标注颜色、笔宽、字号、序号大小和笔刷偏好可跨重启保留；设置窗口按需加载，关闭后沿用空闲资源回收机制。
- 统一序号和文字的预览 / 导出字体与边缘渲染。

## 下载与更新

- `yingtie-0.2.6-win64.zip`：Windows x64 便携包，解压运行 `snipaste-rs.exe`。
- `yingtie-0.2.6.exe`：Windows x64 独立程序。
- `yingtie-0.2.6-macos-arm64.zip`：macOS 14+ Apple Silicon 应用包，解压后将“映贴.app”移入“应用程序”。
- `SHA256SUMS.txt`：上述发布文件的 SHA-256 校验值。

更新前请退出旧版。新设置保存在 Windows 的 `%APPDATA%\Yingtie\settings.toml` 或 Mac 的 `~/Library/Application Support/Yingtie/settings.toml`。首次升级会读取旧版热键文件，替换应用不会清除用户设置。

## 验证与范围

- Mac 完成原生设置、序号预览 / 导出、配置持久化、热键回滚及原有截图、标注、取色、二维码、剪贴板、贴图和资源生命周期验收。
- 发布流程分别在 Windows / macOS 上执行格式检查、零告警代码检查、单元测试和 release 构建，并检查最终压缩包与校验值。
- Windows 新设置与序号工具的桌面交互尚需更多真机验证；Mac 系统保存面板和文件夹选择仍需更多交互验证。
- Windows 程序未进行代码签名；GitHub Mac 应用使用 ad-hoc 签名，未进行 Developer ID 签名和 Apple 公证。本机构建使用已有的持久本机签名。
