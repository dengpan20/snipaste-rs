# 映贴 0.2.8

## 本版更新

- 桌面贴图增加柔和阴影，获得焦点时显示浅蓝色阴影；阴影透明度跟随贴图透明度，保留原图尺寸与清晰度。Windows 和 Mac 共用阴影绘制。
- Windows 贴图窗口不再显示任务栏图标，激活和切换焦点后仍保持隐藏。
- 保存截图和贴图时，默认文件名改为 `截图-20261024-1.png`：按系统本地日期和当天成功保存次数命名，每天从 1 开始，重启后接着累计。
- 截图与贴图、PNG 与 JPEG、不同保存目录共用当天计数；取消或保存失败不占次数，仍可在系统保存窗口中自定义文件名。
- Mac 系统保存面板同步使用新命名规则，日期遵循本地时区；适配 Retina 缩放下的贴图阴影边距。

## 下载与更新

- `yingtie-0.2.8-win64.zip`：Windows x64 便携包，解压运行 `snipaste-rs.exe`。
- `yingtie-0.2.8.exe`：Windows x64 独立程序。
- `yingtie-0.2.8-macos-arm64.zip`：macOS 14+ Apple Silicon 应用包，解压后将“映贴.app”移入“应用程序”。
- `SHA256SUMS.txt`：上述发布文件的 SHA-256 校验值。

更新前请退出旧版，替换应用不会清除用户设置。设置保存在 Windows 的 `%APPDATA%\Yingtie\settings.toml` 或 Mac 的 `~/Library/Application Support/Yingtie/settings.toml`；每日保存计数保存在同目录的 `save-counts.json`。

## 验证与范围

- 发布流程在 Windows / macOS 原生环境执行格式检查、零告警代码检查、单元测试和 release 构建，并校验最终压缩包与 SHA-256。
- Windows 贴图专项验证了透明合成、焦点阴影颜色、切换焦点后的任务栏样式，以及 100%、125%、200% DPI 下原图像素保持。
- Mac 已适配新命名规则与阴影，但本次未在真实 Mac 桌面上手动验收这两项交互；混合 DPI 跨屏拖动仍需更多真机验证。
- 完整原生验收仍有序号标注预览与导出的少量边缘像素差异，本次独立完成贴图专项；详见仓库的 `docs/pin-shadow-verification.md`。
- Windows 程序未进行代码签名；GitHub Mac 应用使用 ad-hoc 签名，未进行 Developer ID 签名和 Apple 公证。
