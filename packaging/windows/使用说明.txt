映贴 @VERSION@ — Windows x64 便携版

快速开始
1. 运行 snipaste-rs.exe，无需安装 Rust。启动新版前，请从托盘退出旧版。
2. 默认按 F1 截图 → 拖动框选 → Enter 确认 → 在其他应用中 Ctrl+V 粘贴。
3. 默认按 F3 将当前选区或剪贴板中的图片贴到桌面。
4. 右键点击托盘图标，选择“退出”可结束程序。

自定义热键
右键点击托盘图标 → 设置… → 点击截图或桌面贴图的按键框 → 按下新组合 → 保存。
保存后立即生效，重启后保留。普通按键需搭配 Ctrl、Alt 或 Win；F1–F24 / PrintScreen 可以单独使用。
两个功能不能使用相同热键。自定义组合被占用时会提示保存失败并保留原设置。
恢复默认后需点击保存；取消或关闭窗口不保存修改。Esc 取消当前按键录入。
设置窗口打开期间暂停两个全局热键，保存或关闭后恢复。
默认截图键被占用时会尝试候选键；菜单和截图界面显示实际生效的热键。
设置位置：%APPDATA%\Yingtie\settings.toml，兼容读取旧版 hotkeys.json。

截图与标注
Enter / Ctrl+C / 勾号 / 双击选区：确认并复制。
Ctrl+S：保存 PNG / JPEG；Ctrl+Z：撤销；Ctrl+Y / Ctrl+Shift+Z：重做。
默认文件名为“截图-年月日-当天保存次数”，例如 截图-20261024-1.png。
当天成功保存后递增，重启后保留，每天从 1 开始；取消或保存失败不占次数。
Q：识别选区二维码；Esc：取消截图。
放大镜显示时按 Shift 切换 HEX / RGB，按 C 复制颜色；框选后按住 Alt 临时取色。
文字输入时 Enter 提交文字，Shift+Enter 换行。

贴图操作
贴图带柔和阴影，获得焦点时显示浅蓝色阴影；贴图窗口不显示任务栏图标。
拖动移动；滚轮缩放；Shift+滚轮调整透明度。
Ctrl+C 复制；右键显示更多操作；Esc 或双击关闭。

注意事项
开启自启后请保持程序位置固定，移动程序后关闭并重新开启自启。
没有贴图时，截图结束空闲 3 秒释放图形设备，下次截图需要重新初始化。
混合 DPI 多屏、独占全屏游戏和受保护视频内容仍需根据设备验证。
当前未提供滚动截图、OCR、贴图历史库和完整高级设置。
Windows 程序尚未进行代码签名。

文件校验与构建来源见 SHA256SUMS.txt 和 release.json。
